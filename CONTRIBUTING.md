# Contribuir

1. Abre una incidencia describiendo el problema o la propuesta.
2. Crea una rama `feat/`, `fix/`, `docs/` o `chore/` desde `main` actualizada.
3. Realiza un cambio acotado y añade pruebas.
4. Ejecuta compilación y pruebas: `dotnet build Coophead.sln -c Release` y `dotnet test Coophead.sln -c Release`.
5. Abre una Pull Request con el motivo, cambios, pruebas y limitaciones.
6. Espera revisión y aprobación antes del merge.

No subas ensamblados del juego, copias de Cuphead, guardados, grabaciones, archivos de configuración personales ni modelos de voz sin licencia compatible.
